# 后台分类管理 API 文档

## 概述

后台分类管理模块提供管理员对博客文章分类的增删改查功能，同时提供无需认证的接口供前台首页获取分类列表。

## 基础 URL

- 后台管理接口：`/api/v1/admin`
- 前台接口：`/api/v1`

## 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {} // 具体数据，可能为对象或数组
}
```

- `code`: 状态码，0 表示成功，非 0 表示错误
- `message`: 提示信息
- `data`: 响应数据，接口成功时返回

## 认证说明

- **强制认证**：后台管理接口必须携带有效的管理员 Token，否则返回 `401 Unauthorized`
- **管理员权限校验**：后台管理接口会校验用户是否为管理员（`role_id = 1`），非管理员返回 `403 Forbidden`
- **无需认证**：前台接口无需认证，任何人都可以访问

## 接口列表

### 1. 获取分类列表（前台接口）

获取所有启用的分类列表，用于首页展示。此接口无需认证。

**请求**

```
GET /categories
```

**认证**：无需认证

**查询参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| status | int | 否 | 分类状态，1-启用，0-禁用，默认只返回启用的分类（status=1） | `1` |

**排序规则**

- 按分类创建时间倒序排列（最新创建的分类在前）

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 5,
      "name": "技术"
    },
    {
      "id": 6,
      "name": "生活"
    }
  ]
}
```

**字段说明**

- 返回数组，每个对象包含：
  - `id`: 分类 ID
  - `name`: 分类名称

**注意事项**

-：此接口只返回启用的分类（status=1）
- 不需要分页，返回所有启用的分类
- 不返回 status 和 created_at 字段

### 2. 获取分类列表（后台管理接口）

获取分页的分类列表。

**请求**

```
GET /categories
```

**认证**：强制认证（需携带管理员 Token）

**查询参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| page | uint | 否 | 页码，默认为 1 | `1` |
| page_size | uint | 否 | 每页数量，默认为 10，最大 50 | `10` |
| status | int | 否 | 分类状态，1-启用，0-禁用，不传则返回所有状态 | `1` |
| keyword | string | 否 | 搜索关键词，匹配分类名称 | `技术` |

**排序排序**

- 按分类创建时间倒序排列（最新创建的分类在前）

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 5,
        "name": "技术",
        "status": 1,
        "created_at": "2025-01-01T12:00:00Z"
      }
    ],
    "total": 10,
    "page": 1,
    "page_size": 10
  }
}
```

**字段说明**

- `list`: 分类对象数组，每个对象包含：
  - `id`: 分类 ID
  - `name`: 分类名称
  - `status`: 分类状态，1-启用，0-禁用
  - `created_at`: 创建时间（ISO 8601 格式）
- `total`: 符合条件的分类总数
- `page`: 当前页码
- `page_size`: 每页数量

### 2. 新增分类

创建一个新的分类。

**请求**

```
POST /categories
```

**认证**：强制认证（需携带管理员 Token）

**请求体**

```json
{
  "name": "技术",
  "status": 1
}
```

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 分类名称，最大长度 50 |
| status | int | 是 | 分类状态，1-启用，0-禁用 |

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 验证分类名称是否已存在，已存在则返回 400
3. 创建分类

**响应**

成功：

```json
{
  "code": 0,
  "message": "创建成功",
  "data": {
    "id": 5
  }
}
```

失败（分类名称已存在）：

```json
{
  "code": 400,
  "message": "分类名称已存在",
  "data": null
}
```

### 3. 编辑分类

更新指定分类的信息。

**请求**

```
PUT /categories/{id}
```

**认证**：强制认证（需携带管理员 Token）

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 分类 ID |

**请求体**

```json
{
  "name": "技术",
  "status": 1
}
```

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | string | 是 | 分类名称，最大长度 50 |
| status | int | 是 | 分类状态，1-启用，0-禁用 |

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 验证分类是否存在，不存在则返回 404
3. 验证分类名称是否与其他分类重复，重复则返回 400
4. 如果状态被改为禁用（`status=0`），检查该分类下是否有关联文章（`type_id`），有关联文章则返回 400（提示该分类下还有文章，不可禁用）
5. 更新分类信息

**响应**

成功：

```json
{
  "code": 0,
  "message": "更新成功",
  "data": null
}
```

失败（分类不存在）：

```json
{
  "code": 404,
  "message": "分类不存在",
  "data": null
}
```

失败（分类下有关联文章，不可禁用）：

```json
{
  "code": 400,
  "message": "该分类下存在文章，不可禁用",
  "data": null
}
```

### 5. 删除分类

删除指定分类（软删除）。

**请求**

```
DELETE /categories/{id}
```

**认证认证**：强制认证（需携带管理员 Token）

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 分类 ID |

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 验证分类是否存在，不存在则返回 404
3. 检查分类下是否有关联文章，有关联文章则返回 400（提示先删除或修改关联文章）
4. 执行软删除操作（设置 deleted_at 字段）

**响应**

成功：

```json
{
  "code": 0,
  "message": "删除成功",
  "data": null
}
```

失败（分类不存在）：

```json
{
  "code": 404,
  "message": "分类不存在",
  "data": null
}
```

失败（分类下有关联文章）：

```json
{
  "code": 400,
  "message": "该分类下存在文章，无法删除",
  "data": null
}
```

### 6. 统计启用分类数量（前台接口）

统计状态为启用的分类数量。此接口无需认证。

**请求**

```
GET /categories/count
```

**认证**：无需认证

**查询参数**：无

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "count": 10
  }
}
```

**字段说明**

- `count`: 状态为启用（status=1）的分类总数

**业务逻辑**

1. 仅统计状态为启用（status=1）的分类
2. 若没有启用分类，`count` 返回 `0`

## 错误码参考

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未授权（Token 无效或缺失） |
| 403 | 禁止访问（非管理员用户） |
| 404 | 分类不存在 |
| 500 | 服务器内部错误 |

## 注意事项

1. 前台接口无需认证，返回所有启用的分类，不包含 status 和 created_at 字段。
2. 后台管理接口要求管理员认证（`role_id = 1`），非管理员用户访问返回 403。
3. 后台获取分类列表接口可以查看所有状态的分类（包括禁用），通过 `status` 参数筛选。
4. 新增和编辑分类时，分类名称不能重复（区分大小写）。
5. 删除分类前需要检查分类下是否有关联文章，有关联文章则不允许删除。
6. 删除分类为软删除，数据不会从数据库中物理删除。
6. 所有时间字段均使用 ISO 8601 格式（UTC 时区）。
