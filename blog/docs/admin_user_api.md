# 后台用户管理模块 API 文档

## 概述

后台用户管理模块提供管理员对**普通用户**（`role_id = 0`）的增删改查操作。所有接口必须由管理员（`role_id = 1`）调用。

## 基础 URL

```
/api/v1/admin
```

## 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {} // 具体数据，可能为对象或数组
}
```

- `code`: 状态码，0 表示成功，非 0 表示错误
- `message`: 提示信息
- `data`: 响应数据

## 认证说明

- **管理员认证**：所有接口必须携带有效的管理员 Token（`Authorization: Bearer <token>`），且用户角色必须为管理员（`role_id = 1`），否则返回 `401 Unauthorized`。

## 接口列表

### 1. 获取用户列表

获取普通用户（`role_id = 0`）的分页列表。

**请求**

```
GET /admin/users
```

**认证**：管理员认证

**查询参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| page | uint | 否 | 页码，默认为 1 | `1` |
| page_size | uint | 否 | 每页数量，默认为 10，最大 50 | `10` |

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 2,
        "user_name": "李四",
        "avatar_url": "",
        "status": 1,
        "created_at": "2026-05-10T10:30:00Z"
      },
      {
        "id": 3,
        "user_name": "王五",
        "avatar_url": "",
        "status": 0,
        "created_at": "2026-05-15T14:00:00Z"
      }
    ],
    "total": 100,
    "page": 1,
    "page_size": 10
  }
}
```

**字段说明**

- `id`: 用户 ID
- `user_name`: 用户昵称
- `avatar_url`: 头像 URL（可能为空）
- `status`: 状态：`1` 正常，`0` 封禁
- `created_at`: 注册时间（ISO 8601 格式）
- `total`: 用户总数
- `page`: 当前页码
- `page_size`: 每页数量

> 注意：接口仅返回 `role_id = 0` 的普通用户，不包含管理员。

### 2. 新增用户

创建一个新的普通用户。

**请求**

```
POST /admin/users
```

**认证**：管理员认证

**请求体**

```json
{
  "user_name": "张三",
  "account": "13800138000",
  "password": "password123456",
  "status": 1
}
```

**参数说明**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| user_name | string | 是 | 昵称，1-15 个字符，不能重复 |
| account | string | 是 | 账号，11 位数字 |
| password | string | 是 | 密码，11-20 位数字和字母的组合 |
| status | int8 | 否 | 状态，`1` 正常（默认），`0` 封禁 |

**响应**

```json
{
  "code": 0,
  "message": "创建成功",
  "data": {
    "id": 4
  }
}
```

**业务逻辑**

1. 校验昵称格式（1-15 个字符）
2. 校验账号格式（11 位数字）
3. 校验密码格式（11-20 位数字和字母）
4. 检查昵称是否已存在，若已存在返回 400
5. 检查账号是否已存在，若已存在返回 400
6. 创建用户，默认 `role_id = 0`

**错误**

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误（字段校验失败） |
| 400 | 昵称或账号已存在 |

### 3. 编辑用户状态

修改指定用户的状态（封禁/正常）。

**请求**

```
PUT /admin/users/{id}
```

**认证**：管理员认证

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 用户 ID |

**请求体**

```json
{
  "status": 0
}
```

**参数说明**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | int8 | 是 | 状态：`1` 正常，`0` 封禁 |

**响应**

```json
{
  "code": 0,
  "message": "更新成功",
  "data": null
}
```

### 4. 删除用户

删除指定用户（软删除）。

**请求**

```
DELETE /admin/users/{id}
```

**认证**：管理员认证

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 用户 ID |

**响应**

```json
{
  "code": 0,
  "message": "删除成功",
  "data": null
}
```

## 错误码参考

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误（字段校验失败、昵称或账号重复等） |
| 401 | 未授权（Token 无效、缺失或非管理员角色） |
| 404 | 用户不存在 |
| 500 | 服务器内部错误 |

## 注意事项

1. 所有接口均需管理员 Token 认证，非管理员调用返回 401。
2. 获取用户列表仅返回 `role_id = 0` 的普通用户。
3. 新增用户时，昵称和账号不能与已有用户重复。
4. 编辑用户接口仅能修改 `status`（封禁/正常），不涉及昵称等个人信息。
5. 删除用户为软删除（`gorm.DeletedAt`），数据不会从数据库中物理删除。
6. 用户列表支持分页，`page_size` 最大为 50。
7. 所有时间字段均使用 ISO 8601 格式（UTC 时区）。
