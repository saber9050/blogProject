# 文章模块 API 文档

## 概述

文章模块提供博客文章的浏览、筛选、点赞等功能。所有接口均遵循统一的响应格式。

## 基础 URL

```
/api/v1
```

## 统一响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {} // 具体数据，可能为对象或数组
}
```

- `code`: 状态码，0 表示成功，非 0 表示错误（具体错误码参考全局定义）
- `message`: 提示信息
- `data`: 响应数据，接口成功时返回

## 认证说明

- **可选认证**：接口支持携带 `Authorization: Bearer <token>` 头部，用于获取用户相关状态（如是否点赞）。若不携带，则返回返回默认状态。
- **强制认证**：接口必须携带有效的 Token，否则返回 `401 Unauthorized`。

## 接口列表

### 1. 获取文章列表

获取分页的文章列表，支持按分类、标签、排序规则和关键词筛选。

**请求**

```
GET /articles
```

**认证**：可选认证

**查询参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| page | uint | 否 | 页码，默认为 1 | `1` |
| page_size | uint | 否 | 每页数量，默认为 10，最大 50 | `10` |
| sort | string | 否 | 排序规则，`latest`（最近发布）或 `popular`（热门推荐），默认为 `latest` | `latest` |
| category_id | uint | 否 | 分类 ID，筛选指定分类的文章 | `5` |
| tag_ids | string | 否 | 标签 ID 列表，多个用英文逗号分隔，筛选包含任意标签的文章 | `1,2,3` |
| keyword | string | 否 | 搜索关键词，匹配文章标题或摘要 | `Go语言` |

**排序规则说明**

- `latest`：按文章创建时间倒序排列（最新发布的文章在前）
- `popular`：按文章热度排序，热度计算公式为：`点赞数 × 3 + 浏览量 × 1 + 评论数 × 2`，热度高的文章在前

**返回规则说明**

- `status`: 只返回状态为 1（状态为已发布）的文章

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 123,
        "title": "文章标题",
        "summary": "文章摘要",
        "cover_url": "https://example.com/cover.jpg",
        "views": 1000,
        "like_count": 50,
        "comment_count": 12,
        "is_liked": false,
        "author_name": "作者昵称",
        "category": {
          "id": 5,
          "name": "技术"
        },
        "tags": [
          { "id": 1, "name": "Go" },
          { "id": 2, "name": "后端" }
        ],
        "created_at": "2025-01-01T12:00:00Z"
      }
    ],
    "total": 100,
    "page": 1,
    "page_size": 10
  }
}
```

**字段说明**

- `list`: 文章对象数组，每个对象包含：
  - `id`: 文章 ID
  - `title`: 标题
  - `summary`: 摘要
  - `cover_url`: 封面图 URL（可能为空）
  - `views`: 浏览量
  - `like_count`: 点赞数
  - `comment_count`: 评论数
  - `is_liked`: 当前用户是否已点赞（仅当携带有效 Token 时返回准确值，否则为 `false`）
  - `author_name`: 作者昵称
  - `category`: 分类对象（可能为空）
  - `tags`: 标签对象数组（可能为空数组）
  - `created_at`: 创建时间（ISO 8601 格式）
- `total`: 符合条件的文章总数
- `page`: 当前页码
- `page_size`: 每页数量

### 2. 获取文章详情

根据文章 ID 获取文章的完整内容。调用此接口会自动增加文章的浏览量。

**请求**

```
GET /articles/{id}
```

**认证**：可选认证

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 文章 ID |

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 123,
    "title": "文章标题",
    "content": "文章完整内容（Markdown/HTML）",
    "cover_url": "https://example.com/cover.jpg",
    "summary": "文章摘要",
    "views": 1000,
    "like_count": 50,
    "comment_count": 12,
    "is_liked": false,
    "author_name": "作者昵称",
    "category": {
      "id": 5,
      "name": "技术"
    },
    "tags": [
      { "id": 1, "name": "Go" },
      { "id": 2, "name": "后端" }
    ],
    "created_at": "2025-01-01T12:00:00Z"
  }
}
```

**字段说明**：同文章列表中的文章对象，但包含 `content` 字段。

**注意事项**：每次调用此接口，文章的 `views` 字段会自动 +1。

### 3. 点赞文章

为指定文章点赞。用户必须已登录。

**请求**

```
POST /articles/{id}/like
```

**认证**：强制认证（需携带有效 Token）

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 文章 ID |

**请求体**：无

**业务逻辑**

1. 验证文章是否存在，不存在则返回 404
2. 检查当前用户是否已点赞该文章：
   - 若已点赞，返回错误码 `400`，提示 "您已经点赞过该文章"
   - 若未点赞，执行点赞操作

**响应**

成功：

```json
{
  "code": 0,
  "message": "点赞成功",
  "data": null
}
```

失败（已点赞）：

```json
{
  "code": 400,
  "message": "您已经点赞过该文章",
  "data": null
}
```

### 4. 取消点赞

取消对指定文章的点赞。用户必须已登录。

**请求**

```
DELETE /articles/{id}/like
```

**认证**：强制认证（需携带有效 Token）

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 文章 ID |

**请求体**：无

**业务逻辑**

1. 验证文章是否存在，不存在则返回 404
2. 检查当前用户是否已点赞该文章：
   - 若未点赞，返回错误码 `400`，提示 "您尚未点赞该文章"
   - 若已点赞，执行取消点赞操作

**响应**

成功：

```json
{
  "code": 0,
  "message": "取消点赞成功",
  "data": null
}
```

失败（未点赞）：

```json
{
  "code": 400,
  "message": "您尚未点赞该文章",
  "data": null
}
```

### 5. 获取文章统计数据

获取已发布文章的统计数据（文章数量、总阅读量、总点赞量）。此接口无需认证。

**请求**

```
GET /articles/stats
```

**认证**：无需认证

**查询参数**：无

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "article_count": 128,
    "total_views": 56000,
    "total_likes": 3200
  }
}
```

**字段说明**

- `article_count`: 已发布文章数量（status=1）
- `total_views`: 已发布文章的所有阅读量之和
- `total_likes`: 已发布文章的所有点赞量之和

**业务逻辑**

1. 仅统计状态为已发布（status=1）的文章
2. 若没有已发布文章，各字段返回 `0`

### 6. 获取随机文章

随机获取一篇已发布文章的 ID。适用于"随便看看"等随机发现场景。

**请求**

```
GET /articles/random
```

**认证**：无需认证

**查询参数**：无

**业务逻辑**

1. 统计已发布文章（status=1）的总数
2. 若总数为 0，返回错误码 `404`，提示 "暂无已发布的文章"
3. 若总数 > 0，生成随机偏移量，返回其中一篇文章的 ID

**响应**

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 123
  }
}
```

**字段说明**

- `id`: 随机到的已发布文章 ID，前端可用此 ID 跳转到文章详情页

失败（无已发布文章）：

```json
{
  "code": 404,
  "message": "暂无已发布的文章",
  "data": null
}
```

## 错误码参考

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未授权（Token 无效或缺失） |
| 404 | 文章不存在 |
| 500 | 服务器内部错误 |

## 注意事项

1. 文章列表和详情接口的 `is_liked` 字段仅在携带有效 Token 时返回准确值，否则始终为 `false`。
2. 点赞/取消点赞接口要求用户已登录，否则返回 401。
3. 点赞接口会校验用户是否已点赞，已点赞则不允许二次点赞。
4. 文章详情接口会自动增加文章的浏览量（`views` 字段 +1）。
5. 文章列表的分页参数 `page` 和 `page_size` 受服务器限制，`page_size` 最大为 50。
6. 所有时间字段均使用 ISO 8601 格式（UTC 时区）。
