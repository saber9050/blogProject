# 后台评论管理 API 文档

## 概述

后台评论管理模块提供管理员对博客评论的查看和删除功能。所有接口均要求管理员认证（`role_id = 1`）。

## 基础 URL

```
/api/v1/admin
```

## 统一响应格式

```json
{
  "code": 0,
  "message": "成功",
  "data": {}
}
```

- `code`: 状态码，0 表示成功，非 0 表示错误
- `message`: 提示信息
- `data`: 响应数据，接口成功时返回

## 认证说明

- **强制认证**：所有接口必须携带有效的管理员 Token，否则返回 `401 Unauthorized`
- **管理员权限校验**：接口会校验用户是否为管理员（`role_id = 1`），非管理员返回 `403 Forbidden`

## 接口列表

### 1. 获取评论列表

获取所有未删除评论的分页列表，按创建时间倒序排列。

**请求**

```
GET /comments
```

**认证**：强制认证（需携带管理员 Token）

**查询参数**

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| page | uint | 否 | 页码，默认为 1 | `1` |
| page_size | uint | 否 | 每页数量，默认为 10，最大 50 | `10` |
| article_title | string | 否 | 搜索关键词，匹配所属文章标题 | `Go并发编程` |
| user_name | string | 否 | 搜索关键词，匹配评论者昵称 | `张三` |
| start_time | string | 否 | 评论开始时间（ISO 8601 格式） | `2026-01-01T00:00:00Z` |
| end_time | string | 否 | 评论结束时间（ISO 8601 格式） | `2026-12-31T23:59:59Z` |

**排序规则**

- 按评论创建时间倒序排列（最新评论在前）

**响应**

```json
{
  "code": 0,
  "message": "成功",
  "data": {
    "list": [
      {
        "id": 1,
        "article_title": "深入理解Go并发编程",
        "user_name": "张三",
        "content": "写得很棒，学习了！",
        "created_at": "2026-07-10T14:30:00Z"
      },
      {
        "id": 2,
        "article_title": "Vue3组合式API入门",
        "user_name": "李四",
        "content": "请问这里怎么处理响应式数据？",
        "created_at": "2026-07-09T10:00:00Z"
      }
    ],
    "total": 100,
    "page": 1,
    "page_size": 10
  }
}
```

**字段说明**

- `list`: 评论对象数组，每个对象包含：
  - `id`: 评论 ID
  - `article_title`: 所属文章标题
  - `user_name`: 评论者昵称
  - `content`: 评论内容
  - `created_at`: 创建时间（ISO 8601 格式）
- `total`: 符合条件的评论总数
- `page`: 当前页码
- `page_size`: 每页数量

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 查询所有未删除的评论（`deleted_at IS NULL`），关联文章表获取文章标题
3. 按创建时间倒序分页返回

---

### 2. 删除评论

删除指定评论（软删除）。使用已有的评论删除逻辑。

**请求**

```
DELETE /comments/:id
```

**认证**：强制认证（需携带管理员 Token）

**路径参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | uint | 是 | 评论 ID |

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 验证评论是否存在，不存在则返回 404
3. 管理员可直接删除任意评论（不限于评论作者）
4. 执行软删除操作（设置 `deleted_at` 字段）

**响应**

成功：

```json
{
  "code": 0,
  "message": "删除成功",
  "data": null
}
```

失败（评论不存在）：

```json
{
  "code": 404,
  "message": "评论不存在",
  "data": null
}
```

---

### 3. 批量删除评论

批量删除选中的评论（软删除）。

**请求**

```
DELETE /comments
```

**认证**：强制认证（需携带管理员 Token）

**请求体**

```json
{
  "ids": [1, 2, 3]
}
```

**请求参数**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| ids | []uint | 是 | 待删除的评论 ID 数组，至少 1 个 |

**业务逻辑**

1. 验证用户是否为管理员，非管理员返回 403
2. 校验 `ids` 数组不为空且元素均为有效 ID，否则返回 400
3. 遍历 ID 列表逐条执行软删除（与单条删除逻辑一致）
4. 不存在的评论 ID 会被跳过，不中断整体流程
5. 返回实际删除成功的数量

**响应**

成功：

```json
{
  "code": 0,
  "message": "批量删除成功",
  "data": {
    "affected_count": 3
  }
}
```

**字段说明**

- `affected_count`: 实际删除的评论数量（不存在的 ID 不计入）

## 错误码参考

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未授权（Token 无效或缺失） |
| 403 | 禁止访问（非管理员用户） |
| 404 | 评论不存在 |
| 500 | 服务器内部错误 |

## 注意事项

1. 所有接口均要求管理员认证（`role_id = 1`），非管理员用户访问返回 403。
2. 获取评论列表仅返回未删除的评论（`deleted_at IS NULL`），已软删除的评论不展示。
3. 管理员删除评论时，不受"仅评论作者可删除"的限制，可直接删除任意评论。
4. 删除评论为软删除（设置 `deleted_at` 字段），数据不会从数据库中物理删除。
5. 所有时间字段均使用 ISO 8601 格式（UTC 时区）。
